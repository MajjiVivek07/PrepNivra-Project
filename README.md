# PrepNivra — Placement Preparation & Progress Tracker

A Core Python project to record student goals, aptitude/Python/interview scores, coding practice, progress reports, and rule-based recommendations.

## Run
1. Extract this ZIP.
2. Open the `PrepNivra` folder in VS Code.
3. Open its terminal and run: `python main.py`

Requires Python 3. Uses only built-in modules. Data is saved in `prepnivra_data.json`.

## Modules
- `main.py`: menu and application flow
- `student.py`: student profile
- `tracker.py`: scores and coding practice
- `analyzer.py`: reports and recommendations
- `storage.py`: JSON save/load

Note: the readiness report is a practice indicator, not a prediction or guarantee of employment.
